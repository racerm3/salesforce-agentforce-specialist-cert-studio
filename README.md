# salesforce-agentforce-specialist-cert-studio

Salesforce Agentforce Specialist Certification Exam Study Guide + Practice Studio

This repository contains a self-contained HTML study app designed to help learners prepare for the Salesforce Agentforce Specialist certification. The experience is organized around an interactive practice studio with:

- an overview section explaining the exam focus and preparation approach
- a study room with scenario-based drills and explanations
- an exam rehearsal mode for timed practice
- a resource library of curated materials and references
- progress tracking that saves work in the browser
- original, certification-aligned questions centered on reasoning, business rules, and agent design patterns

The app is intentionally static and browser-based, requiring no login and no external script dependencies. It is built as a single-page experience for focused practice and review.
